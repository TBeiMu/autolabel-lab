# 局域网服务器训练

「模型训练」可选择本机或局域网服务器。当前支持两台 Linux 服务器：172.21.23.205（两张 RTX 4090 D）和 172.21.23.182（两张 RTX 3090）。标注、数据管理和结果展示仍在本机网页进行。

## 使用方法

1. 在「模型训练」的「服务器 GPU 状态」点击对应服务器的「检测环境与 GPU」。检查剩余显存和利用率；服务器可能有其他用户的任务，状态以检测时为准。
2. 训练位置选择「局域网 GPU 服务器」，选择服务器和 GPU 0、GPU 1 或 GPU 0 + 1。
3. 设置 epochs、尺寸和 batch。双卡的 batch 是两张卡的总 batch，必须是 2 的倍数。
4. 检查训练数据并开始训练。程序将固定的训练和验证快照上传、核验，服务器后台训练，日志和每个 epoch 的曲线回传网页。
5. 训练成功后，`best.pt` 自动回传至本实验 `models/<模型名>/best.pt`，并核验 SHA-256；后续本机自动标注和网页审核按原流程进行。

测试图片、审核参考答案不上传到训练服务器；从父模型继续训练时只另外上传父权重。保持原 YOLO26s-OBB 结构、类别顺序和初始化规则，实际 Python、PyTorch、CUDA 和训练位置记录在模型记录中。

## 连接配置

本机需要 OpenSSH 的 `ssh` 和 `scp`，通过用户已有的 SSH 配置和私钥登录。私钥不经过网页、不上传仓库。先在终端确认能够非交互连接：

```powershell
ssh -o BatchMode=yes -o StrictHostKeyChecking=yes 172.21.23.205 nvidia-smi
```

将根目录 `servers.example.json` 复制为 `servers.local.json`，填写当前用户对应的服务器 Python 和工作目录。`servers.local.json` 留在本机。服务器环境需支持 Python 3.10+、CUDA PyTorch、Ultralytics 8.4.91、PyYAML、psutil；建议创建专用环境，避免修改其他项目依赖。

默认读取已有 SSH Host 配置，用户名和私钥路径可在本机 `~/.ssh/config` 中设置。新服务器需要在终端正常建立并核验 SSH 主机记录，再在网页检测。

## 停止与恢复

关闭浏览器不会停止训练。网页服务重启后，原本机监控进程可以继续提供服务器训练状态。点击任务「停止」会通知远程训练，并等待其结束；双卡进程会一起停止。

SSH 断开会重试。长时间无法重连时，模型显示「远程连接中断」并保留远程任务地址，避免误启动另一个任务。恢复网络后在模型训练页点击「恢复远程任务」，重新接管同一个任务并回传已完成权重。程序不会因断网重新训练。

远程数据和日志位于配置工作目录下的 `jobs/<任务ID>`，保留以便排查。程序不删除服务器上其他用户的进程或数据，同一账户的工作台训练使用 GPU 锁避免重复占用。

双卡训练使用 PyTorch DDP。两张 24 GB 卡分别保存模型副本，显存不会合成一张 48 GB 卡。模型是否能训练取决于每张卡能否容纳单卡模型和该卡分到的 batch。
