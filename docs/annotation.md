# 网页旋转框标注

人工种子标注和模型预测审核均在浏览器完成。模型仍用本地 `.pt` 权重，无需外部标注程序和 ONNX 导出。

## 人工标注与审核入口

在「人工标注」选择种子集、验证集或测试集，点击「进入网页标注」。也可以点击该分组的图片缩略图直接进入。编辑器只在所选分组内翻页，避免将训练和评价图片混在一起。

模型完成预标注后，在「自动标注与审核」选择轮次，点击「进入网页审核」。原始预测显示在对照区，编辑和保存只更新审核标注。删除误检、补漏、调整框和类别后保存；没有预测或没有目标的图片同样需要检查和保存。

## 框选、调整与连续标注

1. 在侧栏选择目标类别，按 **D** 或点「画框」，在图片中拖动绘制矩形。
2. 按 **V** 选择框：拖动框内部移动、四角调整尺寸，上方圆点旋转。按住 Shift 旋转会对齐到 15 度；也可以在侧栏输入角度。
3. 选中框后可以修改类别，按 Delete 删除；也可点击右侧框条目中的垃圾桶图标直接删除对应框。删除其他框时保留当前选择；Ctrl+Z 撤销，Ctrl+Y 重做。归档只读时删除按钮不可用。
   删除后，画布和侧栏按剩余框的顺序连续编号；选中位置移到后一个框，删除末尾框时移到前一个框。
4. Ctrl+S 保存；「保存并下一张」与「上一张」都会先保存当前标注。画面中没有目标时，也要保存空标注。
5. 按 **C** 或点「复制上一张框」，从上一张已保存的标注追加框。当前图片已有的框保留；图片尺寸不同时按宽高比例映射坐标。按当前帧的目标位置和类别调整，最后保存。

按 **M** 或点击「拖选多个框」，拖动选择区域内完整包含的框；选择模式也可以从空白处拖选。按住 Shift 点击画布中的框或右侧框列表，可增减选择。拖选完成后拖动任一选中框，可一起移动；Ctrl+C/Ctrl+V、修改类别和 Delete 同样作用于全部选中的框。多个框的大小和角度需分别选择后调整。

右侧每个框前面的 **⠿** 是排序手柄。拖到另一行的上方或下方调整顺序；选中多个框时，拖动其中一个手柄会将它们作为一组移动，并保留组内顺序。画布、列表和保存的 JSON 顺序同步更新，可撤销重做。聚焦手柄后也可按上下箭头移动顺序；归档标注不能排序。

选中单个框后，按 **Ctrl+C / Ctrl+V**（Mac 使用 Cmd+C / Cmd+V）或工具栏「复制框 / 粘贴框」。在同一张图片粘贴会稍微错开位置，便于继续调整；跨图片粘贴按图片尺寸映射。复制的类别和四角保留，当前其他框不会被覆盖，粘贴也可以撤销。输入框内的复制粘贴仍使用正常文本操作。

滚轮缩放图片，按空格拖动平移，点「适应窗口」恢复全图。标注坐标始终以原图像素保存，缩放不会改变框的位置。

复制上一张适合连续视频帧。已打乱的图片可能来自不同视角，不应直接沿用上一张目标位置。

## 保存、审核确认与固定归档

网页保存会检查图片、类别、四个角点和边界。超出图像、退化的框无法保存，编辑器保留草稿以便继续修正。保存后的 JSON 位于人工分组的 `workspaces/<分组>` 或轮次的 `rounds/<轮次>/editable`。

越界框会显示红色虚线和「越界」标签，侧栏同步高亮并列出待检查的框号。点击「检查框」可将该框定位到画布中央，包括完全位于图片外的框。修正后提示自动消失；尝试保存仍有越界的标注时，会定位第一个越界框并列出需要检查的序号。

关闭编辑器会先保存当前图。未保存的修改暂存在当前浏览器的本地存储中，刷新后打开同一图片可以恢复。保存失败不会自动清空草稿；多页面同时修改同一图片时，会阻止旧页面覆盖新标注。需要放弃当前修改时点击「丢弃草稿并重新加载」。

人工分组全部保存后，回「人工标注」点击「导入标注」完成整批校验和固定归档。网页审核轮次要求每张图片都保存确认，再勾选全批审核并「导入审核结果」，才会进入下一轮训练。保存确认表示用户已检查该图片，不能自动证明标注质量，仍需按实验标准检查漏检和框选。

已经固定归档的种子、验证、测试和审核标注只读，保护历史训练与评价基准。旧实验的 JSON 可以直接读取；尚未归档的旧预测可以进入网页审核。原始预测 `raw` 和固定归档不会被编辑器覆盖。

## 编辑器回归验证

开发时可单独安装 Playwright（`npm install --no-save --prefix _smoke/browser-tools playwright`），再设置 `NODE_PATH` 为该目录下的 `node_modules`，运行 `node scripts/verify_editor.cjs`。验证使用合成图片和独立临时实验，覆盖删除后的画布与列表编号、框复制粘贴、越界定位与修正、保存结果和原始预测保留。默认使用项目 `.venv` 和已安装的 Edge；其他 Python 可用 `ALAB_TEST_PYTHON` 指定。
